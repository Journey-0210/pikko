# 给公司同事的使用指南

## 1. 你会拿到什么

- pikko 插件：在网页上收藏图片、视频，在本地素材库分类、打星和查看来源资料。
- BigSpy 脚本：用固定步骤搜索已配置竞品，按长投放和最新创意筛选，调用插件保存真实原文件和广告数据。
- AI agent 教程：帮助首次安装、核对竞品、配置及诊断故障。

AI agent 负责配置与核对，日常固定步骤由脚本执行。这个包没有内置大模型 API key，也没有团队云端素材库。

## 2. 最容易开始的方法

1. 完整解压 ZIP 到固定目录，路径可以有中文和空格。不要在 ZIP 预览内运行，也不要只拿走 Start 文件。
2. 双击根目录 **开始使用.cmd**（或Start-Here.cmd），回答竞品、调查国家和官网/App链接。没有Node.js时按显示的地址安装，再重新双击。
3. 已安装Codex命令行时会自动启动AI继续配置，使用你自己的AI账号及权限设置；只有桌面App不代表一定有命令行。没有命令行或使用其他agent时，在agent中打开此文件夹，只说“开始”，无需复制AGENT_START.txt。Agent需要能读写本机文件、运行命令，并使用ego-browser。
4. 按 agent 引导完成本人登录、浏览器安装确认和本地目录选择。
5. 等首次小批次验收结果。成功后 agent 会留下你的日常配置和下一次运行方式。

向导只保存你的调查需求，不把未经核实的竞品直接写入正式采集配置，也不会覆盖已有machine/config或素材。再次双击会沿用上次需求继续；要换竞品，在agent里直接说明新需求即可。首次界面为中文问答窗口，不是完整图形安装程序；下载ZIP本身不会自动执行。自动启动参数依据[官方Codex CLI文档](https://learn.chatgpt.com/docs/cli/reference)，项目引导依据[AGENTS.md机制](https://learn.chatgpt.com/docs/agent-configuration/agents-md)。

没有 ego-browser 能力的普通聊天窗口可以解释教程，但不能替你完成本机浏览器采集。此时需要在有本地文件、终端和 ego-browser 能力的 agent 中继续。

## 3. 环境与安装

当前实机验证环境为 Windows + ego lite 的 Chromium。插件是未打包扩展，单独手动使用也可装在允许加载扩展的 Chrome/Edge；自动脚本操作的是 ego 浏览器，因此必须把插件安装在它实际使用的浏览器里。

脚本需要 Node.js 20或以上、ego-browser CLI、FFmpeg。不需要为插件运行 npm install，也不需要另装 Playwright。Agent 应先检查现有安装，缺少时按各工具官方说明配置。包内不捆绑这些运行时、浏览器和 FFmpeg。

安装入口：[Node.js官方下载](https://nodejs.org/en/download)、[ego lite官网](https://lite.ego.app/)、[FFmpeg官方下载说明](https://ffmpeg.org/download.html)。新装Node可选择官网当前LTS版本，现有满足脚本要求的环境先检查再决定是否需要改动。

Windows缺少ego时，从官网下载安装并打开ego，完成首次引导，再新开终端执行 `Get-Command ego-browser` 和 `ego-browser skill`。首次引导需要本人完成；旧终端可能还没读取更新后的PATH。Agent应使用CLI打印的当前指南，不需要复制维护者的skill路径或浏览器profile。FFmpeg的Windows可执行版本按官方说明选择，将实际ffmpeg.exe路径交给setup，不能拿一个下载压缩包或文件夹路径代替可执行文件。

手动安装插件时，在 ego 浏览器打开 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，指向本包的 `extension` 子目录。复制页面显示的实际32位扩展ID交给agent；换电脑或换加载目录，ID可能不同。企业策略禁止加载时，联系公司的设备管理员。

正常登录 BigSpy；需要你本人处理的验证码、登录或浏览器权限框，由你操作。脚本不会代替源站下载权限。

浏览器下载设置应使用默认下载目录并关闭“每次下载询问保存位置”，否则无人值守流程可能等在保存对话框。下载管理插件或其他 BigSpy 页同时下载可能干扰接收；采集期间暂停这些操作。

pikko 使用下载目录下的 `AdVault` 文件夹。首次下载后打开插件素材库，点击“连接本地文件夹”，亲自选择这个 AdVault 文件夹，供本地预览读取。索引里有记录不等于原文件仍存在；预览提示缺失/未授权时按提示重新连接，不要重建空库。

## 4. 首次配置会留下哪些文件

| 文件 | 含义 | 是否给同事直接复用 |
|---|---|---|
| `automation/machine.json` | 这台电脑的扩展ID、FFmpeg位置 | 不复制；每人重新生成 |
| `automation/config.json` | 你的竞品、市场、平台、数量、调查根目录 | 可经核对后复用业务规则；首次用模板新建 |
| `automation/config.example.json` | 不含任何竞品的空模板 | 可以 |
| `creative-families.json` | 这个工作区运行后建立的创意家族去重数据 | 日常保留；不要当初始数据给新同事 |
| `media-fingerprints.json` | 本地文件的指纹缓存 | 不复制 |
| `runs/`、`last-run.json`、`session.json` | 本机运行证据与会话 | 不当初始化配置复用 |

配置缺失时，agent可执行：

```powershell
node automation/setup.mjs --extension-id 这里替换为实际32位ID --ffmpeg "这里替换为FFmpeg可执行文件的完整路径"
node automation/doctor.mjs
```

FFmpeg已在PATH时可省略 `--ffmpeg`。setup只创建缺失文件，不覆盖现有配置；doctor通过只证明命令与配置可用，不能代替浏览器登录、官方下载及真实文件验收。

首次试跑使用长投放2、最新3、候选上限35、15分钟预算。通过后，agent可以整理长投放5、最新10、上限90的日常配置；首次真实运行不自行扩大到全部竞品。

## 5. 日常怎么运行

保持电脑唤醒、网络可用、ego打开且BigSpy登录有效，双击 `automation/Start-BigSpy.cmd`。要停止时双击 `Stop-BigSpy.cmd`，等当前步骤安全收尾；直接关闭窗口不能代替安全停止。

也可以把以下一句发给agent：

> 按当前pikko日常配置运行一轮，使用实际启动器并做正常文件验收；失败先诊断，不人工补抓。请分开报告执行、文件和数量结果，不要改变竞品范围或清空历史去重。

默认目录是“调查根目录 / 竞品 / YYYY-MM / FB或GG”。长投放按完整Running Days排序并标5星；最新创意首次出现日期也须在来源窗口内，排除本期长投放及已知历史创意。缺量可以是历史重复、来源不足、归属不明或原文件不可下载，并不自动说明程序坏了。

同一月份同目录复跑会复用已有记录；排名变化时不会自动删除以前已保存的素材。复用保留原收藏时的数据快照，不会自动刷新广告指标。不同根目录是不同输出范围，不能通过换空目录证明去重通过。

脚本默认读取网站Last 30 Days的实际日期，并写入报告。固定日期可配置 `dateRange`。长投放在窗口内有投放即可，首次出现可早于窗口；最新创意首次出现必须在窗口内。两种口径不同。

当前是按需自动执行，不是已经部署的定时服务。若后续需要每周/每月运行，先完成本机试跑，再明确时间、机器可用性、提醒方式和账号使用安排。

## 6. 怎么看结果

先看 `automation/last-result.txt`，再由agent读取 `last-run.json` 指向的本轮目录。启动失败可能没有新报告，必须核对时间和runId，不能把上一轮结果算成这轮成功。

| 结果 | 应怎样理解 |
|---|---|
| `executionStatus=completed` | 配置中的任务执行结束；不代表数量全部达到 |
| `report.status=partial` | 有数量缺口或候选遗漏；查看各任务原因 |
| `verification.status=passed` | 验收覆盖的真实文件、元数据及原记录检查通过 |
| `empty` | 当前查询无结果，不能当作没有竞争广告的全站结论 |
| `COLLECTION_STOP` | 安全停止，不是整批完成 |
| `DOWNLOAD_COUNT_LIMIT` | 当前请求被源站明确限制；不能推断账号总额度或重置时间 |

停止后恢复也让agent处理：保持同目录、日期、数量及品牌口径，判断能否使用原报告检查点。部分任务会重新搜索并复用已保存文件，不保证从某个像素位置接着点。

## 7. 卡顿、失败和换竞品

网页卡顿时，脚本会在没有待完成下载时最多刷新一次，并保留第一次失败。明确次数限制不会用刷新连续重试。失败后不要手动抓几条来把数量补满，把 `docs/AGENT_PROMPTS.md` 中的故障提示词发给agent，让它检查本轮日志。

新增竞品要核对官网、广告主/账号和真实搜索字段。同名品牌、经销商、广告代理、文案里提到竞品，都可能造成误收。`match`不是随便填一个常见短词，`accountMatch`也不能用过宽关键词绕过检查。

固定脚本目前仅支持Facebook和AdMob。换国家、行业、账号、浏览器或机器后，都先重新核对和试跑；不能把开发者电脑上的验收当成你的环境验收。

## 8. 备份、升级与团队协作

每个人独立保留素材索引和整个AdVault目录。插件导出的索引JSON不是媒体备份；只复制安装包不会带走原文件或浏览器目录授权。

升级时先备份索引、AdVault和自己的配置，更新原加载目录并在浏览器扩展页面点“重新加载”。不要卸载后重装，也不要随意改加载路径；那可能失去原扩展索引或产生另一个扩展ID。升级后重新运行doctor并做小批次。

多个同事共用同一个BigSpy账号时应协调执行时段；每台机器的本地运行锁不能阻止另一台电脑同时下载。此包提供共同的工具和操作方式，不提供多人共享索引或跨机互斥。
