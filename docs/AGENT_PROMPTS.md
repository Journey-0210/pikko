# 可以直接发给 AI agent 的话

先在agent中打开解压后的项目目录，再复制下面对应段落。首次使用的完整文本也在根目录AGENT_START.txt。

## 第一次安装和配置

```text
请阅读当前项目 README.md、AGENTS.md 和 docs/AGENT_PLAYBOOK.md，帮我配置pikko插件和BigSpy脚本。
我的竞品是：〔名称和官网/应用链接〕；市场：〔国家〕；平台：〔Facebook/AdMob或两者〕。
检查本机环境和实际扩展ID，沿用已有可用安装，核对BigSpy搜索名、广告主和投放账号。不要沿用别人的电脑路径、TaskSpace或历史缓存。
先用一个已核对竞品跑2条长投放+3条最新的小批次（最多35候选、15分钟），验证真实图片/视频及来源数据；失败先诊断，不人工补抓。通过后整理我的日常配置，默认5+10、最多90候选，但首次不自行扩大到全部竞品。只把确需本人登录/授权和无法推断的信息交给我处理。
最后给我：配置位置、实际验证结果、缺量/阻塞/未测范围、启动停止方式，以及下一次运行的一句话。
```

## 日常运行

```text
请按当前pikko日常配置运行一轮。先检查无其他采集和pending、BigSpy登录及官方控件可用；执行实际Start入口，不改变竞品/国家/平台/目录。正常结束后执行verify，分开报告执行、文件质量与目标数量，给出准确runId和证据路径。遇次数限制停整轮，其他失败先诊断，不人工补抓、不清空去重。配置不完整时先指出缺项。
```

## 新增或修改竞品

```text
请在现有pikko调查中〔新增/替换〕这些竞品：〔名称、官网/应用链接〕。目标市场和平台：〔填写〕。
先备份当前配置，核对真实BigSpy广告主、账号和搜索字段，再更新必要的brands配置。不要只凭文案提到品牌就归属，不要加过宽accountMatch或未经核实的reviewedAds。新的市场/行业先做独立小批次，使用不同口径时不要复用旧检查点。保留已有素材和历史去重。完成后说明改变了什么及哪些范围实际测过。
```

## 停止并恢复

```text
请用Stop-BigSpy.cmd安全停止当前pikko采集，核对无孤立pending并保留成功文件。然后在相同品牌、目录、日期、数量、国家和行业条件下恢复；如需更改条件先说明。核对检查点是否可用，不可用则重新搜索并复用成功文件。不要把停止轮报成完成，也不要改写旧report。最后报告父/恢复runId、停止收尾时间、复用/新增及是否有重复记录。
```

## 出错或卡住

```text
pikko采集出错/停住了，请先诊断，不重装、不清库、不人工补抓。
读docs/AGENT_PLAYBOOK.md，核对last-run时间、原始report/events、截图和pending，区分未触发下载、源站拒绝、下载中断、来源不匹配、页面等待及文件验收失败。保留首次失败和已有文件。明确COUNT EXHAUSTED时停止，不猜总额度和恢复时间；UI卡顿遵循最多一次安全刷新。确需改代码时保存新版本证据，跑相关回归再做新一轮小批次，不能拼接旧版本成功结果。给我根因证据、修复/阻塞、未测范围和下一步。
```

## 换电脑或升级

```text
请按TEAM_GUIDE检查pikko迁移/升级。先盘点并备份本人的索引、AdVault原文件和配置，保留原扩展加载目录与数据。新电脑重新识别扩展ID和FFmpeg位置，不复制旧session/lock/绝对路径缓存，也不认为复制安装包就迁移了素材库。沿用业务竞品规则前重新核对本机页面，完成doctor和真实小批次，再交付可运行状态；无法验证的部分明确写未测。
```
