# pikko.

Pick it. Keep it.

Your little space for big ideas.

本地图片/视频收藏与管理插件。团队安装、BigSpy脚本和首次配置见 [团队使用指南](../docs/TEAM_GUIDE.md)。

安装时选择本文件所在的extension目录（包含manifest.json），无需构建。日常收藏在素材角落点击收藏，选择目标文件夹、星级、标签并保存。只有真实下载完成才算成功。BigSpy只走当前页面可用的官方下载控件。

打开素材库并连接下载目录内的AdVault文件夹，可预览真实原文件。下载目录和浏览器索引分别保留，导出索引不是媒体备份。升级保持原加载路径和本地数据，不卸载重建。

This unpacked extension stores metadata locally and saves media below the browser's Downloads/AdVault directory. Connect that folder in the library for local previews. It does not provide a cloud team library. The BigSpy automation requires separate local configuration; see the team guide and agent playbook.

普通网页的收藏适配范围、BigSpy权限及未测范围以团队包版本说明为准，不能保证所有网站或账号都能下载。
